定义与几何意义

∀ ε > 0，∃ N ∈ ℕ⁺，∀ n > N：
|aₙ − a| < ε

无论给定多小的 ε，都能找到一个正整数 N，使其后的所有项严格落在两条水平线 y=a−ε 与 y=a+ε 之间。带外项至多有限个，带内包含无穷多项。

N 一般依赖 ε；定义只要求存在 N，本实验对可解析验证的案例给出最小正整数 N。因为使用 n>N，编号 N 的项本身允许在边界上或带外。

若全部项已在带内，按“正整数 N”的约定最小值仍为 1。有限散点图只能帮助观察，不能直接证明无限尾项的性质。

严格计算 N 的方法

对于 aₙ=1/n 或 (-1)ⁿ/n、a=0：误差为 1/n，要求 n>1/ε。因此最小正整数 N=max(1,⌊1/ε⌋)。

对于 aₙ=0.8ⁿ、a=0：要求 n>ln(ε)/ln(0.8)，故 N=max(1,⌊ln(ε)/ln(0.8)⌋)。临界整数还会复核边界判定。

对于常数零数列、a=0，所有项均在 ε 带内，N=1。对任意自定义表达式，本程序只检查前 M 项，不声称自动证明极限或求出全局最小 N。

发散对照与量词辨析

(-1)ⁿ：奇数项为 −1，偶数项为 1。对任何候选 a，至少有一个值与 a 的距离不小于 1；取 ε=0.5，无论 N 多大，总有 n>N 的项落在带外，因此不存在实数极限。

aₙ=n：对任何有限候选 a 和任意 ε>0，只要 n>a+ε，就在带外；不可能满足有限极限的定义。

“发散时无论 ε 如何取都有无穷多项在带外”并非对所有发散数列都成立，例如 (-1)ⁿ 对 a=0、ε=2 全部在带内。正确否定是：存在某个 ε₀>0，使任何 N 后仍有带外项。本实验 ε∈[0.001,0.5]，两个发散案例均无可行 N。

实验步骤与观察记录

① 选择 1/n，令 ε 从 0.5 降到 0.001，比较 N 的变化。② 在 ε=0.1 时检查第 10 项与第 11 项，理解严格不等号。③ 切换交错收敛数列，观察正负交替不会阻止收敛。④ 对比两个发散案例，观察无限尾项为何不能全部进入邻域。

结论：收敛控制的是“全部足够靠后的项”，不是只有若干项接近 a，也不是只需满足某一个固定 ε。
