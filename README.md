# 高等数学交互实验

三个实验均为独立HTML文件，无需安装软件或联网加载依赖。可用浏览器打开本地文件，也可通过GitHub Pages在线下载使用。

## 文件说明

- index.html：网站首页，包含实验入口和简易教程。
- curvature.html：第三章，平面曲线曲率与曲率圆实验。
- derivative.html：第二章，导数定义与几何意义交互实验。
- sequence-limit.html：第一章，数列极限 ε–N 实验。
- README.md：仓库说明及使用教程。
- DEPLOY.md：GitHub Pages 发布步骤。


## 实验一：数列极限 ε–N

1. 打开 sequence-limit.html，默认数列是 1/n，候选极限 a=0。
2. 拖动 ε 滑块，范围是 0.001～0.5。绿色点严格在邻域内，橙色点在带外或边界上。
3. 设置 ε=0.1，此时最小正整数 N=10。第 10 项等于 0.1，在边界上；从第 11 项起，所有项满足 |aₙ−a|<0.1。
4. 把 ε 改为 0.01，观察 N 变为 100；改为 0.001，N=1000。此时把采样上限改为 5000，才能看到 N 之后的点。
5. 切换 (-1)^n/n，观察交替正负的数列同样可以收敛。切换 (-1)^n 或 n，观察发散对照和页面解释。
6. 自定义通项如 sin(n)/n，设置候选极限，点击“应用表达式”。自定义数列只提供有限采样检查，不把采样结果当作无限尾项的证明。
7. 可切换“完整数列范围”查看被邻域放大视图裁去的点，移动指针查看数值，使用“自动调节”演示变化。
8. 在页面下方填写观察记录，点击“导出实验记录 TXT”保存。

注意：对预设收敛案例，候选极限设为 0 时才提供相应解析 N。定义使用 n>N，且邻域为严格不等式。N 的最小值按正整数约定为 1。只看到有限项接近 a，不能证明收敛。

## 实验二：导数定义与几何意义

1. 打开“导数几何意义交互实验.html”，默认函数为 f(x)=x²，考察点 x₀=1，初始步长 |h|=1，左右割线同时显示。
2. 输入或拖动考察点 x₀，观察原函数曲线、考察点 P₀、左右割线与切线，以及斜率和误差数值的同步变化；也可点击或拖动图中位置选取考察点。
3. 拖动步长滑块，在 0.001≤|h|≤1 范围内调整步长。选择“右侧”“左侧”或“左右同时对比”，观察平均变化率 [f(x₀+h)−f(x₀)]/h 随 h 趋近 0 的变化。
4. 默认函数在 x₀=1 处的理论导数为 2。初始 |h|=1 时，左割线斜率为 1，右割线斜率为 3；减小 |h|，观察两侧斜率趋近 2、绝对误差减小，割线逐渐贴合切线。
5. 选择“|x|：尖点”，在 x₀=0 处观察左侧差商为 −1、右侧差商为 +1。左右导数不相等，因此函数在原点连续但不可导。
6. 选择“∛x：垂直切线”，在 x₀=0 处减小 |h|，观察左右差商持续增大。其极限为 +∞，原点处存在垂直切线 x=0，但不存在有限的普通导数。
7. 选择“生物工程：底物饱和响应”，观察模型 v(S)=2S/(1+S)。在 S=1 处，瞬时变化率为 0.5；改变考察点，理解导数如何反映反应速率对底物浓度的敏感程度。具有实际意义的浓度范围为 S≥0。
8. 自定义函数可输入 sin(x)、exp(x)、log(x) 等，点击“应用函数”后进行观察。乘法需显式输入 *，实数立方根可输入 cbrt(x)。自定义函数的导数采用数值估计，不能仅凭有限采样严格判定可导性。
9. 点击“自动逼近 h → 0”，观察步长逐渐减小至 0.001 的动态过程，可随时暂停；通过“视野半径”滑块或鼠标滚轮调整缩放，点击“重置当前案例”恢复案例初始设置。
10. 对照实时反馈与差商表格，记录不同步长下的左右斜率及误差，比较光滑点、尖点和垂直切线三种情形，理解“可导必连续，连续不一定可导”。数学原理与生物工程背景可在页面中阅读。
    
## 实验三：曲率与曲率圆

1. 打开 curvature.html，默认抛物线 y=a*x^2，初始参数 a=0.5。
2. 拖动考察点 x₀，观察 f(x₀)、一阶和二阶导数、曲率 K、曲率半径 ρ，以及曲率圆和圆心的同步变化。
3. 默认参数下在 x₀=0，K=1，ρ=1；将参数 a 改为 1，此时抛物线 y=x² 的顶点 K=2，ρ=0.5。
4. 选择“圆”，默认 R=2，沿圆移动考察点，应观察到 K≈0.5、ρ≈2。改变 R，比较 K=1/R。
5. 选择“直线”，观察 K=0、ρ=∞，没有有限曲率圆；选择“半立方尖点”，在 t=0 观察曲率不定义的提示。
6. 自定义函数可输入 sin(x)，选择参数形式则可输入 x(t)=2*cos(t)、y(t)=sin(t)。设置递增区间后点击“应用表达式 / 重置视图”。
7. 点击或拖动图中曲线选点；也可“自动演示”。曲线超出视野时点击“适配曲线”，或调整缩放。
8. 填写观察记录并导出 TXT。医学工程背景与数学原理可在页面下方阅读。

注意：曲率以数值微分近似计算，奇异点、定义域边缘和极端参数可能无法稳定计算。颜色表示当前曲线内部的相对曲率，不能直接按颜色跨案例比较。圆过大或圆心超出视野时会被裁切。
